# Бодлого 13: Өвлийн хүйтэн (Псевдокод)

## Алгоритмын алхмууд:

1. **Эхлэл**
2. **Хувьсагчдыг зарлах:**
   - `celsius`: Реал төрлийн массив (7 элементтэй, Цельсийн температурыг хадгалах)
   - `fahrenheit`: Реал төрлийн массив (7 элементтэй, Фаренгейтийн температурыг хадгалах)
   - `category`: Текстэн төрлийн массив (7 элементтэй, дулаахан/тас хүйтэн ангиллыг хадгалах)
   - `mintemp`: Реал төрөл (Хамгийн хүйтэн температурыг хадгалах)
   - `day`: Бүхэл тоо (Хамгийн хүйтэн өдрийн дугаарыг хадгалах)
   - `i`: Бүхэл тоо (Циклийг удирдах тоолуур)

3. **Температурын өгөгдлийг оруулах болон хөрвүүлэх (Цикл i = 0-ээс 7 хүртэл):**
   - Хэрэглэгчээс i+1 дэх өдрийн Цельсийн температурыг уншиж авна (`Input celsius[i]`)
   - Фаренгейт рүү хөрвүүлэх томьёо: `fahrenheit[i] = celsius[i] * 9 / 5 + 32`
   - Хэрэв `celsius[i] > -30` бол:
     - `category[i] = "маш хүйтэн"`
   - Эсрэг тохиолдолд бол:
     - `category[i] = "Дулаахан"`

4. **Хамгийн хүйтэн өдрийг олох алгоритм:**
   - Анхны утга оноох: `mintemp = celsius[0]`, `day = 1`
   - Цикл ажиллуулах (i = 1-ээс 7 хүртэл):
     - Хэрэв `celsius[i] < mintemp` бол:
       - `mintemp = celsius[i]`
       - `day = i + 1`

5. **Үр дүнг хэвлэх:**
   - 7 хоногийн өдөр бүрийн хөрвүүлсэн Фаренгейтийн хэм болон ангиллыг жагсаалтаар хэвлэнэ.
   - "Хамгийн хүйтэн өдөр: " + `day` + "-дэх өдөр (" + `mintemp` + "°C)" гэж хэвлэнэ.
6. **Төгсгөл**
