\# АЛГОРИТМ, ПРОГРАМЧЛАЛЫН ХЭЛ (APLI21)



\### 1. Төслийн тодорхойлолт

Энэхүү repository нь Алгоритм, програмчлалын хэл хичээлийн лабораторийн ажлуудыг хадгалах зориулалттай.



\### 2. Доторх файлууд

\- hello.c: Эхний долоо хоногийн "Hello, UFE" хэвлэх код.

\- README.md: Төслийн заавар болон мэдээллийн файл.



\### 3. Программыг ажиллуулах заавар

C хэл дээрх кодыг ажиллуулахын тулд:

1\. GCC компилятор ашиглан компил хийнэ: gcc hello.c -o hello

2\. Үүссэн программыг ажиллуулна: ./hello
